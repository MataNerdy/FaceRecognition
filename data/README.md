# Data

Данные не хранятся в репозитории. Для воспроизведения экспериментов положите локальные датасеты сюда или передайте путь через CLI-аргументы скриптов.

Ожидаемые варианты:

```text
data/
├── raw/                  # исходные изображения, например CelebA
├── aligned/              # выровненные лица для классификатора
└── eval/                 # query/distractor splits для IR-оценки
```

Локальные архивы `aligned_eval_query.zip` и `aligned_eval_distractors.zip` вынесены за пределы репозитория в соседнюю папку `FaceRecognition_local_artifacts/`.
